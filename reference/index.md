# Package index

## Explain predictions

Compute (approximate) Shapley values and related effect decompositions
for the predictions of any supervised learning model.

- [`explain()`](https://bgreenwell.github.io/fastshap/reference/explain.md)
  : Fast approximate Shapley values
- [`explain_effects()`](https://bgreenwell.github.io/fastshap/reference/explain_effects.md)
  [`print(`*`<explain_effects>`*`)`](https://bgreenwell.github.io/fastshap/reference/explain_effects.md)
  : Main, total, and interaction effect decomposition

## Data
